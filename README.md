# Терминальное приложение "Конвертор"

---

## Описание проекта

Терминальное приложение "Конвертор" — это учебно-демонстрационное приложения для перевода одних величин в другие.

**Цель проекта:**
- Изучение инструментов и технологий для создания приложений
- Изучение принципов ООП
- Изучение возможностей ЯП Java
- Создание приложения для перевода одних единиц в другие
---

## Основные возможности

- **Перевод одних единиц веса в другие**
- **Перевод одних единиц длины в другие** 
- **Перевод одних единиц температуры в другие**
- **Перевод одних единиц валюты в другие** 
- **Изучить инструкцию заказа пиццы**
- **Сохранить исчисления в отдельный файл**
- **Загрузить ранее сделанные исчисления в программу**

## Архитектура приложения

В основе программы лежат 4 класса, отвечающие за перевод одних единиц в другие. Они наследуют класс SupConvertor
и реализовывают интерфейс Convertor. 

SupConvertor отвечает за то, чтобы у всех классов был 1 конструктор, 
который принимает в себя объект класса Data_to_convert. Data_to_convert - record класс, объекты которого содержат 2 поля:
- String to_convert_to - что во что переводится
- int enterNumber - сколько единиц переводится

Интерфейс Convertor отвечает за то, чтобы все классы реализовывали метод convert(). 
Это позволяет нам не задумываться о деталях реализацииконвертирования и о том, что мы конвертируем. 
Мы просто вызваем это конвертирование там, где надо.

Отдельно упомяну класс Money_Convertor. 
Чтобы конвертировать одну валюту в другую, нужно знать их текущий курс.
Для получения информации приложение обращается к сервису https://app.currencyapi.com/.
